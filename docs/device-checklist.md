# Device checklist

Manual checks to run on real hardware before a gate that touches audio, mic, or install (Gates 5, 7, 9, 17, 23, 24). Report the result in `PROGRESS.md`.

Devices: iPhone Safari, iPad Safari (landscape), Mac Safari, Mac Chrome. Test with both wired and Bluetooth headphones.

- [ ] Audio starts after one tap
- [ ] Sound plays with the iPhone silent switch on
- [ ] Sound plays with the iPhone silent switch off
- [ ] Microphone permission prompt appears and works
- [ ] Tuner reads a real guitar string correctly
- [ ] App installs to the home screen
- [ ] App works offline after install
- [ ] Layout holds up after rotating the device
- [ ] Text stays usable at the largest system text size
