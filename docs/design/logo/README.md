# Atelier Six logo: VI Monogram

The chosen mark: a Roman-numeral **VI** in a high-contrast serif (thick–thin V, stemmed I), a faint hairline above, and a **brass nut line with a brass dot** below, like the maker's stamp inside a handmade instrument.

All letterforms are drawn as paths, so the logo looks identical everywhere and never depends on a font being installed.

| File | Use |
|---|---|
| `vi-mark-dark.svg` | The mark on dark backgrounds (default: bone `#EFEAE1` + brass `#B8925A`) |
| `vi-mark-light.svg` | The mark on light backgrounds (ink `#1B1714` + dark brass `#8A6A35`) |
| `vi-favicon.svg` | Browser tab and anything ≤ 32 px: no hairline, no dot, thicker brass line |
| `vi-app-icon-1024.svg` | Master for iOS / Android / PWA icons (full-bleed; the OS rounds the corners) |
| `vi-maskable-1024.svg` | Android adaptive / PWA maskable icon (mark kept inside the 80 % safe zone) |

**Wordmark:** "ATELIER SIX" in Geist 500, uppercase, letter-spacing 0.34em, set beside or below the mark. The wordmark is live text in the app (not part of the SVGs).

**Clear space:** at least the height of the brass dot × 3 on every side. **Minimum size:** 16 px (use the favicon version below 32 px).

**Don't:** recolour the brass, add effects or shadows, stretch, or put the dark version on a light background.
