# 4. Pure core and generated data

Date: 2026-09-26

## Status

Accepted

## Context

The engine, schedules and lessons are the product. Mistakes there (a wrong fingering, a bar
that doesn't add up, an unplayable stretch) are musical bugs users hear. Hand-written chord
tables and lessons drift and are hard to check.

## Decision

- All logic lives in `src/core` with no DOM, audio or React imports, and 100% unit-test
  coverage.
- Chord shapes, lessons and tunes are generated by scripts in `scripts/data/` from compact
  sources and genre style sheets, validated (`checkPlayable`, `checkHarmony`, `checkBars`,
  `lintAgainstStyle`), and written to `src/data/*.json`. Nobody edits the JSON by hand.

## Consequences

- The core can be tested in milliseconds and reused from Node scripts.
- Every lesson is guaranteed playable and in style; a bad edit fails the build.
- Adding content means editing a source file and rerunning a script, not editing JSON.
