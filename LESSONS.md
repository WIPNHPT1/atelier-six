# Lessons (read before every step)

Format — one line each: `- [area] symptom → cause → fix (step)`
Rules: max 60 lines. When full, merge similar lines. Never delete a lesson that is still true.
Areas: build, ts, lint, test, e2e, audio, pwa, ui, data, engine, ci, netlify, detect, db, native.

## Seeded (known pitfalls)
- [audio] AudioContext silent/suspended → no user gesture → call `Tone.start()` inside a click handler; in Playwright, Firefox/WebKit never treat a dispatched click as real user activation even with a real click + Tone.start() → `test.skip(browserName !== 'chromium', ...)` on audio-gesture e2e specs (5.2)
- [test] Tone.js import crashes in jsdom → Web Audio missing → keep scheduling pure in `src/core/schedule`, mock `src/audio` in UI tests (5.x)
- [netlify] deep links 404 → SPA routing → `/* /index.html 200` redirect in netlify.toml (0.8)
- [ci] `npm ci` fails → lockfile out of sync → run `npm install` locally and commit the lockfile (0.7)
- [pwa] stale app after deploy → old service worker → `registerType: 'autoUpdate'` + prompt to reload (9.1)
- [ui] iOS tilt sheen does nothing → DeviceOrientation needs permission → request on a tap, fall back to time-based sheen (9.2)
- [audio] clicks on bends/whammy → setValueAtTime jumps → use `linearRampTo`/`rampTo` and 5 ms gain ramps (11.3, 14.1)
- [audio] live Whammy sounds late → granular PitchShift adds window latency → playback uses detune directly; PitchShift only for live input (14.4)
- [audio] mic pitch wrong/unstable → browser echo cancellation/AGC on → request audio with processing flags off (12.2)
- [ui] MIDI pedal button missing on iPhone → Web MIDI unsupported in Safari → feature-detect, show on-screen rocker (14.2)
- [data] phrase build fails on bar length → durations must sum to 16 per `|` bar (11.1)
- [detect] mic analysis wrong pitch → AudioContext runs at 44.1/48 kHz but Basic Pitch needs 22,050 Hz → resample in the worklet (16.1)
- [detect] tfjs in the entry chunk → static import → dynamic `import()` inside the worker only (16.2)
- [netlify] VITE_ env var undefined in prod → added after the last deploy → trigger a redeploy after changing env vars (18.1)
- [db] query returns empty for the signed-in user → RLS policy missing or wrong → every table needs select/insert/update/delete policies on `user_id = auth.uid()` (18.1)
- [pwa] ML model or WASM blocked → CSP → self-host under /models and add `'wasm-unsafe-eval'` to script-src (23.2)
- [native] no sound on iPhone with silent switch on → AVAudioSession category → AudioSession plugin sets `.playback` (24.2)
- [build] never block on an interruption: a usage limit mid-step → checkpoint commits + RESUME.md, new session + /pickup; the live site paused on used-up monthly Netlify credits → keep building, mark DEPLOY_PENDING, deploy after reset (all)
- [audio] sample licence unclear → can't ship it → read the licence file first; record source and attribution in docs/licences.md; fall back to the plucked-string model (5.5)
- [pwa] install too big → samples in the precache → runtime-cache samples on first use, offer "Download sounds for offline" (5.5)
- [data] lesson fails style lint → built from scratch instead of style cells → rebuild it with riffBuilder from the style JSON (6.0)
- [build] "Operation not permitted"/EPERM on git config/remote, husky/lint-staged, gh, git push, npm/tsx/vitest touching node_modules → sandbox protects .git/config, ~/.gitconfig, the keychain and this drive's node_modules → rerun that one command outside the sandbox; a host the command can't reach → name it in the command's allowed domains; never widen the sandbox settings (all)
- [ui] axe "color-contrast" on a dimmed badge/pill → `opacity: 0.5` blends text and background into the page → use a full-opacity vetted colour pair; axe "button-name" on `<Button loading>` → `visibility: hidden` drops the label from the name → use `color: transparent` (Gate 5, Gate 1)

## Learned during build
- [build] external drive writes AppleDouble `._*` sidecars for every file → tools crash parsing them and git warns "non-monotonic index" for `.git/objects/pack/._pack-*` → exclude `**/._*` in eslint/vitest/playwright configs; `rm -f` stray `._*` files (safe, not real objects) before committing (0.1-0.4, all)
- [test] jsdom gaps: RTL "multiple elements found" across `it` blocks (no auto-cleanup without `globals: true`) and `window.matchMedia is not a function` → `afterEach(cleanup)` and a matchMedia stub in `src/test/setup.ts` (1.2, 1.3)
- [lint] real components fail on every SVG/DOM attribute (`role`, `type`, `d`, `cx`…) → `react/jsx-no-literals` had `ignoreProps: false` from phase 0 → set `ignoreProps: true`; it still catches hardcoded JSX text children (1.2)
- [ts] strictTypeChecked: numeric template literals → `String(n)`; `arr[i]!` banned and `noUncheckedIndexedAccess` gives `T | undefined` → guard with `=== undefined`; spreading a `let` narrowed by a ternary fails "Spread types may only be created from object types" → build the object from named fields (1.2, 3.4, 3.5)
- [ts] `npm run verify` never caught real type errors → root `tsconfig.json` has `files: []` + references, so plain `tsc --noEmit` checks nothing → script must be `tsc -b --noEmit` to actually build-check the referenced projects (1.3)
- [ts] CSS Modules import types as an index signature → `noUncheckedIndexedAccess` makes every `styles.foo` a `string | undefined` → don't put them straight into a `Record<K, string>`; type such maps `Record<K, string | undefined>` and join classnames with a small `cx()` helper (`src/ui/cx.ts`) (1.3)
- [ui] `<Logo variant="lockup" size={28}>` silently dropped the wordmark → the "small drawing below 32px" auto-switch also applies to lockup, so any size <32 skips the wordmark span → pick a size ≥32 wherever the lockup/wordmark must show (1.4)
- [e2e] Playwright typing: `@axe-core/playwright` has no default export → `import { AxeBuilder }` + `import type { Result } from 'axe-core'`; `page.evaluate()` needs DOM lib → e2e has its own `tsconfig.tests.json` with `lib: ["ES2023","DOM"]` (1.5, 1.6)
- [ui] react-hooks rules: reading `getComputedStyle` for token swatches raced the settings effect → derive from the settings store; resetting state via `useEffect` on a prop change trips `set-state-in-effect` → mount only while open (fresh `useState`) or reset during render (1.5, 1.6)
- [e2e] CLS assertions flaky → View Transitions add a sub-pixel `layout-shift` per route change, and a lazy route's first visit shifts from its Suspense fallback → assert `toBeLessThan(0.01)` and warm the route chunk with a throwaway navigation before observing (1.6)
- [test] 100% core coverage: `noUncheckedIndexedAccess` guards are unreachable and flagged, and `vitest --coverage src/core` only runs core tests (UI-only branches miss) → write loops index-free so impossible guards don't exist; keep edge cases in `src/core/edges.test.ts` (3.5, Gate 6)
- [ci] `git commit` rejects a made-up scope (e.g. `feat(library): ...`) → commitlint only allows a fixed enum → check `commitlint.config`/the allowed list and use the closest existing scope, e.g. `ui` for a feature page (4.4)
- [e2e] stale or racy runs: `reuseExistingServer` reuses an old preview on :4173 → `lsof -nP -iTCP:4173 -sTCP:LISTEN` and kill it; a helper's `page.goto('/')` reload means shell key listeners aren't attached yet → navigate in-app (`history.pushState` + `popstate`), which also keeps just-saved IndexedDB progress in memory (4.4, 6.5)
- [test] RTL queries: a button wrapping a Fretboard gets a concatenated name → give it its own `aria-label`; a Slider is a native range (no aria-valuenow) and `as HTMLInputElement` trips lint → `screen.getByRole<HTMLInputElement>('slider', …).value` (4.4, 6.4)
- [lint] eslint `react-hooks/immutability` fails a `let` reassigned inside `.map()`/a loop during render (e.g. accumulating an x-cursor for SVG note positions) → build the running total with `.reduce()` returning a fresh object each step, never mutate a captured `let` (4.5)
- [e2e] a `/design` full-page screenshot came back nearly empty after adding more lazy-loaded content → `page.goto()` only waits for the `load` event, not the async component finishing its render → `await` a locator for the page's last element (e.g. `scrollIntoViewIfNeeded()`) before `page.screenshot()`, same for axe scans (Gate 4)
- [ui] React #185 (max update depth) → zustand selector returning a new object each call → `useShallow` or one primitive per call; a store reachable from the always-mounted shell must not statically import Tone → dynamic `import()` in its actions, check the entry chunk after `npm run build` (5.4)
- [audio] realism: distorted palm mutes ring together → end muted notes early and filter before the drive; review said playback sounded "AI generated" → humanise the band (timing/velocity/drum detune, hat accents, fills), one note per string (new hit releases the old, chord change damps unstruck strings), strum taper + upstrokes on top 4 strings, muted "chk", second guitar instead of a synth pad (Gate 5, Gate 6)
- [ui] custom slider clicks but won't drag (worst on touch) and segmented labels spill out → styled fill/handle overlay swallowed the press on the hidden 1px native thumb; segments had fixed `height` → drag with Pointer Events + `setPointerCapture` on a 44px `touch-action: pan-y` hit area (native input kept, `pointer-events: none`, for keyboard/AT); use `min-height` for any box holding wrappable text (fix)
- [ui] overlay (sheet/dialog) drawn under the floating search button/dock, close button unreachable → page content renders inside PageHeader's sticky `z-index: 10` stacking context, and a class passed to IconButton lost its `display: none` to IconButton's own CSS (chunk order) → `createPortal` overlays to `document.body`; put position/visibility on a wrapper element, never on a shared component's class (fix)
- [ts] `tsc -b` fails TS1543 on a JSON import once a `scripts/` file (NodeNext) pulls in a `src/` module that imports JSON → add the import attribute `import x from './x.json' with { type: 'json' }` (Vite and Node both accept it) (6.0)
- [data] power-chord lesson/tune fails `shift-speed` (12 fret/s is real) on 3–4 fret jumps in an eighth → render the strokes before the change as muted throwaway strums, as many as the jump needs, across section boundaries, never past the previous chord; don't filter candidates by register (D5/A5 have no 'low' shapes) (6.1, 6.7)
- [ui] palette query ("tun") picked a lesson over Tuner once lessons were registered → groups were shown in fixed order (Lessons first) → order groups by their best fuzzy score; and a lazily imported module in AppShell throws EnvironmentTeardownError in App.test → `await vi.dynamicImportSettled()` (6.2)
- [audio] playback and display out of step → loop end was the last strum (use whole bars, wrap the playhead by `getLoopSeconds()`); tempo change restarted from the remaining bars (keep the full source, resume at the same beat via `resumePosition`); TabLane matched a column index against sixteenths (columns carry `time`, light `activeColumn`); playhead read the scheduled-ahead Transport time (use `getSecondsAtTime(currentTime − output latency)`); `sync.test.ts` guards audio vs tab (6.3, Gate 6)
- [detect] pitchy locks onto a spurious near-DC "pitch" (clarity 1.0) on quiet/decaying buffers even past the RMS gate → also reject results outside a plausible instrument range (e.g. 55–1500 Hz) (7.1)
- [e2e] mic e2e: Playwright needs `--use-fake-ui-for-media-stream --use-fake-device-for-media-stream`, but with echoCancellation/noiseSuppression/autoGainControl off (needed for real mic accuracy) Chromium's synthetic generator emits a hard-clipped click, not a tone → also add `--use-file-for-fake-audio-capture=<wav>` with a real sine fixture; a click right after an in-app route swap can land mid view-transition and get swallowed by the snapshot overlay → wait for the target visible + a short settle pause first (7.2)
- [audio] Metronome/Count-in toggles change the UI but nothing audible happens → schedule's `click`-kind events were built correctly but the Part callback only ever called `playEvent` (no-ops on their empty `strings`), never `playClick`; count-in clicks also sit at negative `t`, which `Tone.Part` drops, and `loopStart` clips the *whole* first playthrough, not just repeats → give the count-in its own one-shot Part and `.start()` the looping content Part later, at the offset (fix)
- [lint] `test.beforeEach(({}, testInfo) => ...)` for a project-name skip guard trips `no-empty-pattern`, but Playwright requires that first param destructured (a named param throws at runtime) → keep `{}` and add `// eslint-disable-next-line no-empty-pattern` (Gate 8)
- [audio] tuner works in Chromium but reads nothing on real Safari (iPhone/Mac) even after granting mic permission → three stacked Safari-only causes device testing caught one by one: AudioContext starts suspended (`await audioContext.resume()`), Safari only pulls data through nodes reaching the destination so a dead-end analyser gets none (route it through a muted `GainNode` to `audioContext.destination`), and real quiet acoustic input (0.002 rms, clarity 0.99) was below an RMS gate tuned against loud fake/desktop signal (dropped 0.01 → 0.0008); an on-screen rms/freq/clarity readout made this diagnosable without a console (Gate 7)
